# 개인정보 처리방침

시행일: 2026-05-03

하루정리는 사용자의 하루 기록을 정리하기 위해 필요한 최소한의 정보만 처리합니다. 본 문서는 앱 출시 전 초안이며, 실제 사업자 정보, 연락처, 서버 운영 방식이 확정되면 배포 전에 최신 정보로 교체해야 합니다.

## 수집하는 정보

- 사용자가 입력한 하루 기록
- 앱 내 프로필 정보: 이름, 이메일
- 앱 사용 설정: 구독 단계, 알림 시간, 개인정보 보호 모드
- AI 분석 결과: 소비, 할 일, 감정, 메모, 내일 계획

## 수집하지 않는 정보

- 위치 정보
- 연락처
- 사진 또는 마이크 권한을 통한 원본 데이터
- 광고 식별자

## 이용 목적

- 하루 기록 분석 및 요약 제공
- 소비, 할 일, 감정, 메모, 내일 계획 생성
- 사용자 설정 저장
- 구독 기능 제공 및 고객 지원
- 서비스 품질 개선

## 보관 및 삭제

현재 앱의 기본 저장 방식은 기기 내 저장입니다. 서버 AI 분석 기능을 연결하는 경우, 분석 요청 처리를 위해 입력 내용이 서버로 전송될 수 있습니다.

사용자는 고객 지원을 통해 계정 정보와 서버 저장 데이터를 삭제 요청할 수 있습니다. 기기 내 데이터는 앱 삭제 시 함께 삭제됩니다.

## 제3자 제공

하루정리는 법령상 의무가 있는 경우를 제외하고 사용자의 개인정보를 제3자에게 판매하거나 임의 제공하지 않습니다.

AI 분석, 결제, 고객 지원 등 서비스 제공에 필요한 외부 처리 업체가 있는 경우, 해당 업체와 처리 목적을 본 방침에 명시합니다.

## 아동 개인정보

하루정리는 만 14세 미만 아동을 주요 대상으로 하지 않습니다. 만 14세 미만 사용자의 개인정보 처리가 필요한 경우 법정대리인의 동의를 받습니다.

## 보안

하루정리는 개인정보 접근 권한을 제한하고, 서버 연결 시 HTTPS를 사용합니다. API 키와 AI 제공자 인증 정보는 앱에 직접 포함하지 않고 서버에서 관리합니다.
