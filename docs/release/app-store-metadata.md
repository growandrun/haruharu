### 설명

하루정리는 하루 동안 있었던 일을 자유롭게 적으면 AI가 소비, 할 일, 감정, 메모, 내일 계획으로 정리해주는 생활 관리 앱입니다.

복잡한 가계부나 투두 앱처럼 항목을 하나씩 나눠 입력할 필요가 없습니다. 오늘 쓴 돈, 미룬 일, 해야 할 연락, 컨디션, 중요한 메모를 한 문장으로 남기면 하루정리가 보기 좋게 분류합니다.

주요 기능:

- 하루 기록 입력
- 소비 내역 자동 분류
- 해야 할 일 자동 추출
- 감정 상태 요약
- 오늘 요약 카드
- 내일 계획 자동 생성
- 주간 리포트

추천 대상:

- 기록은 하고 싶지만 정리가 귀찮은 사람
- 메모, 가계부, 투두리스트를 따로 쓰기 번거로운 사람
- 하루를 짧게 돌아보고 내일을 가볍게 준비하고 싶은 사람

하루가 복잡할수록, 정리는 단순해야 합니다.
그냥 적으세요. 정리는 하루정리가 합니다.

현재 버전은 사용자가 직접 입력한 텍스트를 바탕으로 하루 기록을 정리합니다. 민감한 권한은 사용하지 않으며, 실제 AI 서버 연결 시 사용자 기록은 개인정보 처리방침에 명시된 목적에 한해 처리됩니다.
